# Yofa Firmansyah — Portfolio (Neo-Brutalism)

Website portofolio pribadi dengan desain **Neo-Brutalism** yang menonjolkan estetika berani, border tebal, dan kontras warna yang tajam. Dibangun dengan fokus pada kecepatan performa dan desain yang modern.

## 🚀 Demo
Lihat live demo di sini: [yofa.github.io/portofolio](https://yofa.github.io/portofolio/) *(Ganti dengan link GitHub asli setelah dideploy)*

## ✨ Fitur Utama
- **Neo-Brutalism Aesthetic**: Shadow tajam, border 4px, dan palet warna kontras (#F3F4F6, #2563EB, #FACC15).
- **Responsive Design**: Optimal di berbagai layar (Mobile, Tablet, Desktop).
- **Interactive Elements**: Hover effects "press-in", scroll reveal animations, dan infinite marquee.
- **YouTube Integration**: Lazy-load embed video untuk performa optimal.
- **Modern Tech Stack**: Menggunakan Vite sebagai bundler dan Tailwind CSS untuk styling.

## 🛠️ Tech Stack
- **HTML5** (Semantic Elements)
- **Tailwind CSS v3**
- **JavaScript** (ES6+)
- **Vite** (Build Tool)
- **Google Fonts** (Space Grotesk & Inter)

## 📦 Cara Menjalankan Secara Lokal

1. **Clone Repository**
   ```bash
   git clone https://github.com/username/portofolio.git
   cd portofolio
   ```

2. **Install Dependensi**
   ```bash
   npm install
   ```

3. **Run Dev Server**
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173/` di browser Anda.

4. **Build untuk Produksi**
   ```bash
   npm run build
   ```
   Hasil build akan tersedia di folder `dist/`.

## 📂 Struktur Proyek
- `index.html`: Struktur utama halaman.
- `src/style.css`: Konfigurasi CSS dan design system Neo-Brutalism.
- `src/main.js`: Logika interaktivitas dan animasi.
- `public/images/`: Aset gambar dan logo.
